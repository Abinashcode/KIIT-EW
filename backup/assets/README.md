# Assets Folder

This folder contains all image assets for the website.

## Folder Structure

Place your images in this folder with the following naming conventions:

### Background Images
- `facility-bg.jpg` - Background watermark image for the facilities section

### Logo Images
- `kiit-logo.png` - KIIT logo (PNG format)
- `kiit-logo.svg` - KIIT logo (SVG format)

### Student Photos
- `students/` - Create a subfolder for student photos
  - `student-1.jpg`
  - `student-2.jpg`
  - etc.

### Faculty Photos
- `faculty/` - Create a subfolder for faculty photos
  - `faculty-1.jpg`
  - `faculty-2.jpg`
  - etc.

### Other Images
- Add any other images as needed (gallery images, section backgrounds, etc.)

## Usage

All image paths in the CSS and HTML should reference this folder:
- CSS: `url('assets/image-name.jpg')`
- HTML: `src="assets/image-name.jpg"`
