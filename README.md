# KIIT Higher Secondary School Website

## Image Requirements

Please add the following images to the `images/` folder:

1. **Logo**: `images/logo.png` or `images/logo.jpg` - KIIT entrance wings logo
2. **Hero Images** (3 images for scrolling carousel):
   - `images/hero1.jpg`
   - `images/hero2.jpg`
   - `images/hero3.jpg`
3. **About Section Images**:
   - `images/about1.jpg` - For Guru Shishya Parampara section
   - `images/about2.jpg` - For Mission section
4. **Kalam Image**:
   - `images/kalam.jpg` - Dr. APJ Abdul Kalam portrait

## File Structure

- `index.html` - Main homepage
- `admission.html` - Admission page
- `inquiry.html` - Inquiry/Contact page
- `facilities.html` - Facilities page
- `achievements.html` - Achievements page
- `style.css` - Custom styles
- `script.js` - JavaScript for date/time and hero slider
- `images/` - Image directory

## Features Implemented

1. ✅ Header navigation with live date/time
2. ✅ Main navbar with logo and menu buttons (hover effects)
3. ✅ Hero section with infinite scrolling image carousel
4. ✅ About section with alternating image/text layout
5. ✅ APJ Abdul Kalam motivation message section
6. ✅ Faculty section with gradient styling
7. ✅ Separate HTML pages for each menu item

## Technologies Used

- HTML5
- Bootstrap 5
- JavaScript
- Custom CSS
